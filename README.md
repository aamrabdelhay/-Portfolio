# Amr Abd El-Hay — Portfolio

Personal legal portfolio: achievements, contact, portrait, and scrollable copies of selected websites.

## Run

```bash
npm install
npm start
```

Opens on port `3000`.

## Admin

- Open `/admin` from the key icon in the header
- Set `ADMIN_PASSWORD` in the environment (default is for local use only)

From the studio you can add achievements, attach photographs, and upload a portrait.

## Website copies

- **El Sharaby Law** — `/embed/elsharaby/`
- **SAFA** — `/embed/safa/`
- Other project frames live under `/previews/`

These are viewable copies, not the live production domains.
